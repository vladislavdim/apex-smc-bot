# APEX V3 completion matrix

This is the release gate for the single V3 pull request. `DONE` means code,
tests, production wiring and legacy-path removal are complete. `PARTIAL` never
qualifies for release.

## Delivery policy

- One local branch: `feature/apex-v3-production`.
- One pull request, created only after every row is `DONE`.
- No strategy geometry or risk change during the migration.
- One controlled worker/dashboard deployment after green CI.
- `PRODUCTION_STABLE` only after 48–72 hours of acceptance monitoring.

## Non-negotiable final checks

- No scheduled or request-reachable Shadow/Research/Replay/Backtest path.
- No AI or Learning authority to mutate production rules.
- Gate is the only scanning market source; Binance is execution-only.
- New entry is impossible before `READY` or under a safety inhibit.
- Manager acts only on a confirmed Binance position.
- Every real trade has the complete correlation and version chain.
- Every optional context value has provenance, freshness and `UNKNOWN != ZERO`.
- Five strategy golden suites match the pre-migration production behaviour.
- No duplicate signal, entry or protective order under restart/retry tests.
